# PWA Icons

This directory contains the shipped production icon set for Member Hub.

Current assets:

- Android launcher icons: `member-hub-android-any-144.png`, `member-hub-android-any-192.png`, `member-hub-android-any-512.png`
- Android maskable icons: `member-hub-android-maskable-192.png`, `member-hub-android-maskable-512.png`
- iOS touch icons: `member-hub-ios-120.png`, `member-hub-ios-152.png`, `member-hub-ios-167.png`, `member-hub-ios-180.png`, `member-hub-ios-1024.png`
- Unraid container icon: `member-hub-unraid-icon.png`

The artwork is intentionally text-free with generous padding so it remains
legible for Unraid docker containers, Android maskable launchers, and iOS home
screen icons.
